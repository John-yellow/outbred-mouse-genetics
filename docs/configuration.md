# Configuration and inputs

Copy `config/pipeline.env.example` to `config/pipeline.env`, then edit paths. Paths are resolved relative to the repository root unless absolute. Do not commit machine-specific paths or credentials.

`config/sample_manifest.example.tsv` shows the required tab-separated columns: `sample_id`, `group`, `sex`, `r1`, and `r2`. One row represents one animal; `r1` and `r2` point to the quality-controlled paired FASTQ files. Keep manifest order stable because it defines sample order in joint calls.

`config/ploidy.tsv` describes male X non-PAR haploidy and diploid autosomes/female X. The X pseudoautosomal interval is excluded from the windows generated by the calling script.

Required external assets are the GRCm39 reference FASTA and index, a matching VEP 115 cache, BWA-MEM2, samtools, FastDup, bcftools, VEP, PLINK 2, and R. Their public sources and applicable versions are listed in `envs/README.md`. Large sequence and variant files are intentionally not tracked in Git.
